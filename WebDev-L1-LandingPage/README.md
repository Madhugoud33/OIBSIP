# Nimbus Landing Page

A responsive static landing page created for the Oasis Infobyte Web Development & Designing — Level 1, Task 1 submission.

## Features

- Sticky navigation with links to Features, Stories, and About
- Hero section with headline, supporting text, and call-to-action
- Feature, testimonial, and about sections
- Footer with contact and social-link placeholders
- Consistent warm cream, teal, orange, peach, lavender, and mint colour palette
- Responsive layouts for desktop and mobile screens
- Semantic HTML and accessible navigation labels

## Tech Stack

- HTML5
- CSS3 (Flexbox, Grid, responsive media queries)

## Run Locally

1. Download or clone this folder.
2. Open `index.html` in any modern web browser.
